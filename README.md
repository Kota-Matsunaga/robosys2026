# seikei

標準入力からテキストを読み込み、全角英数字・句読点・余分な空白の表記ゆれを整えて標準出力へ出力するコマンドラインツールです。

## 誰の役に立つか・利用シーン

* **レポートやメモ、下書きを書く人**：箇条書きやメモを清書する前に、全角/半角の混在や句読点、余計な空白をサッと揃えたいとき。
* **テキストデータを別の処理に渡す人**：パイプ（`|`）と組み合わせて、前処理として文字列の表記を一定ルールに整えたいとき。

## 使い方

標準入力（`sys.stdin`）から1行ずつ入力を受け取り、整形後の結果を標準出力（`sys.stdout`）へ返します。エラーは標準エラー出力（`sys.stderr`）へ出力されます。

```bash
printf "  ＲＯＳ２の期限は １１月２６日,２３：５５です.  \n" | ./seikei
